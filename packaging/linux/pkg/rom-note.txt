
 ==================================================================
  Prop Cycle / Rave Racer / Tokyo Wars / Dirt Dash / Time Crisis / Ace Driver / Cyber Commando / Cyber Sled / Time Crisis 2 are installed.  THE GAMES NEED ROM FILES.
 ==================================================================
  No game data is included. Put the MAME ROM sets here:

    Prop Cycle:  propcycl.zip
                 -> ~/.local/share/namco-2x-systems/propcycle/roms/

    Rave Racer:  raverace.zip  AND  namcoc74.zip
                 -> ~/.local/share/namco-2x-systems/raverace/roms/

    Tokyo Wars:  tokyowar.zip
                 -> ~/.local/share/namco-2x-systems/tokyowar/roms/

    Dirt Dash:   dirtdash.zip  (and dirtdasha.zip, if your MAME set has one)
                 -> ~/.local/share/namco-2x-systems/dirtdash/roms/

    Time Crisis: timecris.zip
                 -> ~/.local/share/namco-2x-systems/timecris/roms/

    Ace Driver:  acedrive.zip  AND  namcoc74.zip
                 -> ~/.local/share/namco-2x-systems/acedriver/roms/

    Cyber Commando:  cybrcomm.zip  AND  namcoc74.zip
                 -> ~/.local/share/namco-2x-systems/cybrcomm/roms/

    Cyber Sled:  cybsled.zip  AND  namcoc67.zip  AND  namcoc68.zip
                 -> ~/.local/share/namco-2x-systems/cybsled/roms/

    Time Crisis 2:  timecrs2.zip
                 -> ~/.local/share/namco-2x-systems/tc2/roms/

  (Folders from an older namco22 install, ~/.local/share/namco22/, are used as they are.)

  (Each user has their own folder. Starting a game once creates it
   and opens it for you. Zips already in ~/Downloads are found
   automatically.)  Then start "Prop Cycle", "Rave Racer", "Tokyo Wars", "Dirt Dash", "Time Crisis", "Ace Driver", "Cyber Commando", "Cyber Sled" or "Time Crisis 2"
  from the applications menu, or run:  propcycle / raveracer / tokyowars / dirtdash / timecrisis / acedriver / cybercommando / cybersled / timecrisis2
 ==================================================================
